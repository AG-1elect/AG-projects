# AG Projects

**Public collection of Adam’s engineering project files**

A curated archive of CAD models, PCB designs, schematics, firmware, photographs, and build notes from electronics and engineering projects.

## Project areas

| Area | Description |
|---|---|
| [Electronics](Electronics/) | Circuits, PCB designs, power supplies, and electronic builds |
| [Mechatronics](Mechatronics/) | Projects combining mechanical design, electronics, and control |
| [3D Printing](3D-printing/) | Printable models, CAD parts, and practical accessories |
| [Others](Others/) | Experiments and projects outside the main categories |


## Repository contents

Projects may include:

- CAD and 3D models
- Schematics and PCB layouts
- Wiring diagrams
- Firmware and source code
- Enclosures and printed parts
- Photographs and assembly notes
- Calculations and test results
- Component lists and measurements

The files provided vary by project.

## Getting started

1. Browse a project category.
2. Open the relevant project folder.
3. Review its documentation and diagrams before use.
4. Check component ratings, power requirements, and any safety considerations.

## Safety notice

Some projects involve mains electricity, high currents, batteries, or rotating machinery.

These materials are provided for educational and reference purposes. Always verify the design independently, use appropriate protective equipment, and take reasonable safety precautions. Do not connect or operate unfamiliar circuits until you understand them.
