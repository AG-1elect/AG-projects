# AG Projects

My engineering projects in electronics, mechatronics, and 3D printing.

This repository brings together design files, schematics, PCB layouts,
CAD models, code, and build notes. Available files vary by project.

## Explore the projects

| Section | What you'll find |
|---|---|
| [Electronics](Electronics/) | Circuits, PCB designs, power supplies, and electronic builds |
| [Mechatronics](Mechatronics/) | Projects combining mechanical design, electronics, and control |
| [3D Printing](3D-printing/) | Printable models, practical parts, and accessories |
| [Others](Others/) | Experiments and projects outside the main categories |

## Using this repository

Open a section, then choose a project to access its files and documentation.
Each project has its own folder.
