# ATX Bench Power Supply — shared project files

This folder contains the downloadable enclosure model archive for the DIY ATX bench power supply documented in [Adam's portfolio](https://ag-portfolio-5bi.pages.dev/projects/atx-bench-power-supply/).

## Downloads

- [ATX enclosure STL files (RAR archive)](./ATX-enclosure-STL-files.rar)

Extract the archive with software that supports RAR files. Check the dimensions and fit against your own components before fabrication; the files are provided as-is.

## Safety

This project contains an ATX power supply connected to mains electricity. Mains voltage can cause fatal electric shock, and internal capacitors can retain dangerous charge after unplugging. A short circuit or overloaded wiring can cause burns or fire. Do not open or modify a mains-powered supply unless qualified to do so. Disconnect power before handling, use suitable insulation and correctly rated protection, and have the completed assembly inspected by a qualified person. The 6 A rail fuses described in the project do not make the device safe by themselves. The published material is a project record, not a tested construction guide or safety certification.
