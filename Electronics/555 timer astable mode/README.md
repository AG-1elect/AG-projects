# NE555 Astable Timer PCB

A compact SMD board I designed in KiCad around the NE555 timer in astable mode. The circuit is designed to flash an LED, with an onboard trimmer to adjust the blinking rate.

This project covers schematic capture, component placement, PCB routing, and 3D visualization.

## Project files

- **ne555.rar** — KiCad project archive.
- **PNG images** — Schematic, PCB layout, and 3D board preview.

This folder hosts the downloadable design files and previews for the project presented in my portfolio.
