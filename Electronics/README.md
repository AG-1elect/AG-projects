# Electronics

This is where I document my work in electronics, from early circuit sketches and calculations to PCB layouts and bench measurements. I’m interested in how a circuit works, why a design choice makes sense, and what changes when the circuit meets real hardware.

## Using this repository

Browse the folders by topic. Each folder keeps related files together. When a folder includes a README, start there for design notes, file descriptions, and guidance on opening the files.

For KiCad designs, keep the project files in the same directory and open the `.kicad_pro` file to access the schematic and PCB layout.

## Reading the results

Calculated values describe what I expect from the design. Simulations show how a model behaves under specific conditions. Bench measurements show what happened on physical hardware. I distinguish these in the notes so you can tell what has been verified and what still needs testing.
